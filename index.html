Vercel 배포 여부는 각 저장소의 GitHub 메타데이터에 등록된 홈페이지 주소(*.vercel.app)로 확인했다. 커버 이미지는 저장소 안에 cover.* 파일이 있으면 그것을, 없으면 GitHub Open Graph 이미지를 대신 썼다. private로 표시된 저장소는 코드 링크가 로그인 없이는 열리지 않을 수 있다 — 배포된 화면은 그대로 볼 수 있다.
